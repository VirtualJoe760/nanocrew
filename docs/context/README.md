# Context Layer

This folder is the **working layer** — how to build in this repo and the rules that keep it from
breaking. The rest of `docs/` is the **domain layer** (how the product actually works). New here?
Read [`CONTEXT_GUIDE.md`](CONTEXT_GUIDE.md) — the plain-English onboarding guide.

## The canonical read-order
The root [`CLAUDE.md`](../../CLAUDE.md) loads the core of this order (AGENTS → NEVER_VIOLATE →
CODE_STANDARDS → your division doc); the full canonical read-order for picking up any task is:

1. [`../../AGENTS.md`](../../AGENTS.md) — what this is, the five deployable units, documentation discipline.
2. [`PROJECT_OVERVIEW.md`](PROJECT_OVERVIEW.md) — the product, the user flow, and what's in/out of scope.
3. [`NEVER_VIOLATE.md`](NEVER_VIOLATE.md) — the hard rules. **Read before any change.**
4. [`CODE_STANDARDS.md`](CODE_STANDARDS.md) — how we write code (types, naming, errors, the pre-push gate).
5. [`../architecture/TECH_STACK.md`](../architecture/TECH_STACK.md) — the full technology inventory (the "library-docs").
6. The **division doc** for your task — storefront · studio · accounts · app (see [`../README.md`](../README.md)).
7. [`UI_TOKENS.md`](UI_TOKENS.md) · [`UI_RULES.md`](UI_RULES.md) · [`UI_REGISTRY.md`](UI_REGISTRY.md) — when touching UI.
8. [`../roadmap/REMAINING_FEATURES.md`](../roadmap/REMAINING_FEATURES.md) — what's in flight vs. scope.

The **library-docs** ([`TECH_STACK.md`](../architecture/TECH_STACK.md)) and the **progress-tracker**
([`REMAINING_FEATURES.md`](../roadmap/REMAINING_FEATURES.md)) live in their domain folders and are
linked above — they aren't duplicated here.

## Memory & review are automatic
Keeping these docs current (memory) and self-checking (`tsc` + lint + sync checks) before each commit
(review) are **behaviors, not commands** — see the "working loop" in [`CODE_STANDARDS.md`](CODE_STANDARDS.md).

## The skills that maintain this layer (occasional, optional)
In [`.claude/commands/`](../../.claude/commands): **/architect** (plan a big/ambiguous feature against
these docs), **/recover** (rebuild context after a long session), **/imprint** (refresh these docs
from the code), **/instructions** (regenerate `CONTEXT_GUIDE.md`).
